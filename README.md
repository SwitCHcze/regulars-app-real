# Regulars

**The same small group, once a week, for something easy.**

Regulars puts university students into small groups of up to six who meet once a week for 8 weeks. It's the same people every week, so strangers become friends. It's free for students: universities and halls pay a fee per term, and local partner businesses pay a small fee when members use their discounts.


> This is a **demo copy**. It's the real Regulars student app, but the server has been swapped for recorded example data. The programme, venues, host and other students are made up. Nothing you enter is saved or sent.
> Use the strip at the top of the phone to jump between stages: waiting list, offered a place, or in a group.

## Install it on your phone
Open the link above on your phone, then:
- **Android (Chrome):** tap **Install app** in the browser menu, or the "Add Regulars to your home screen" button in the app.
- **iPhone (Safari):** tap **Share**, then **Add to Home Screen**.

Once installed, it opens full screen with its own icon and works without internet. You don't need an app store.

## Download the files
Click the green **Code** button above, then **Download ZIP**. Unzip the folder and double-click `index.html` to open it in your browser. There's nothing to install and no build step.

## What's in this folder
| File | What it does |
|---|---|
| `index.html` | The page: all the app's screens. |
| `app.js` | The app's code: sign-up, this week, group, vote, support, profile. |
| `styles.css` | How it looks: colours, layout, light and dark mode, university themes. |
| `demo.js` | Demo mode: answers the app's server requests with example data, so nothing is saved or sent. |
| `demo-data.js` | The recorded example data the demo uses. |
| `fonts/` | The app's fonts (Archivo, Figtree, JetBrains Mono), so it needs no outside requests. |
| `manifest.webmanifest` | Lets phones install it as an app (name, colours, icon). |
| `sw.js` | Lets the installed app open offline. |
| `icons/` | App icons. |
| `OVERVIEW.md` | What Regulars is, how it works, privacy rules and tech. |
